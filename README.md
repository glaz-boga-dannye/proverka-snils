# Проверка СНИЛС: что можно узнать о собственных данных

Запросы «пробить СНИЛС», «пробить ФИО по СНИЛСу» и «найти СНИЛС по паспорту» смешивают разные задачи. СНИЛС является личным идентификатором. Его номер не следует публиковать или использовать для поиска сведений о постороннем человеке. Эта страница посвящена проверке своих документов и защите данных, а не получению чужого номера.

## Если нужно уточнить свой номер

Проверьте собственные документы и личный кабинет официального сервиса, через который вам доступна информация о лицевом счёте. Если сведения не совпадают, обращайтесь в уполномоченный орган по официальным каналам. Не вводите паспорт и СНИЛС на случайных сайтах, обещающих мгновенно показать чужие данные.

## Можно ли узнать человека по номеру СНИЛС

Сам по себе номер не даёт публичного права на ФИО, адрес или другие сведения. Утверждения, что любой бот достоверно выдаёт владельца по СНИЛС, стоит проверять особенно строго. Совпадение в старой записи может быть ошибочным или относиться к иному контексту. Не используйте такие фрагменты для идентификации человека без его согласия.

## Если номер оказался в открытом доступе

Не копируйте его в комментарии и поисковые запросы. Сохраните ссылку на место публикации, попросите владельца страницы удалить данные и проверьте свои аккаунты на признаки несанкционированного доступа. При подозрении на злоупотребление обратитесь в компетентную службу через официальный канал.
